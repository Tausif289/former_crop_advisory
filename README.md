Farmer Crop Advisory App 🌾

Empowering farmers with smart, data-driven crop decisions!

Live Demo : https://farmer-bl1m.onrender.com/

🚀 Overview

The Farmer Crop Advisory App is an AI-powered platform for farmers to make informed decisions about crop selection, soil health, disease management, market prices, and government schemes. It integrates real-time data, AI insights, and an intuitive dashboard to maximize yield and profitability.

🧠 Tech Stack
Frontend: ⚛️ React.js | 🎨 Tailwind CSS | 🔗 Axios | 🖼 Lucide Icons
Backend: 🟢 Node.js | ⚙️ Express.js | 🤖 Gemini AI / Google AI API
Database: 🗄 MongoDB Atlas
Authentication: 🔐 JWT-based Secure Login/Signup
APIs: 🌦 OpenWeatherMap | 💰 Govt. Mandi Price API | 🤖 Gemini AI API

🏠 Features
Smart Farm Dashboard

📊 Overview of farming activities, crop health, and AI insights
🧾 Tracks: Sowing | Fertilizing | Pesticide | Harvest | Uploads
🌾 Crop Table → Name, Fertilizer, Pest, Dates, Status Badge
⚡ Actions: Add ➕ | Edit 🖊 | Delete ❌ | View 🔍

Crop Recommendation

🌱 Inputs: Soil Type (auto) + Market & Risk Preference
📤 Outputs:
✅ Top recommended crops
🌾 Soil suitability %
💹 Expected yield & 💰 Market trend
📆 Ideal sowing window

Soil Health – Smart Analyzer
🧪 Upload Soil Report (PDF/CSV) or enter NPK, pH, Organic Matter
📊 Suggests fertilizers & organic improvements
🌿 “Improve Soil” checklist for actionable steps

Crop Health – AI Disease Detection (Gemini 🤖)

📸 Upload or capture crop images
🔍 Detects disease, severity & confidence %
💊 Suggests remedies, dosage, and safety tips

Crop Farming Guide
📚 100+ crop insights
🌱 Sowing time | 🚜 Land prep | 💧 Irrigation | 🐛 Pest management | 🌾 Harvest
🔍 Search any crop → Get detailed guide instantly

Market Price (Real-Time)
📍 Auto location detection
Shows live mandi prices (retail & wholesale)
🔗 Powered by Govt. APIs

Weather Forecast
🌤 5-day forecast: rain %, temperature, humidity, wind, sunrise/sunset
🔗 Powered by OpenWeatherMap API

Government Schemes
📄 Displays scheme info + direct links to official sites
🖥 Clean card UI with “Visit Website” buttons

Community Feedback
🗣 Farmers can post, edit, delete & reply to feedback
🔐 Only post owners can modify their content

AI Chatbot (Gemini 🤖)
💬 Ask farming questions in any language
✨ AI replies with accurate agricultural information
🖥 Chat UI supports attachments & auto language detection

User Profile
👨‍🌾 Name, Email, Location, Soil Type
✏ Edit Profile | 🔐 Password Management | 🚪 Secure Logout
